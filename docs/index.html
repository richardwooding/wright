A coding agent that asks first.

wright runs a coding agent in your terminal with approval-first permissions, an OS sandbox around every shell command, secrets that never leave your machine, no telemetry, and an audit trail you can verify.

safety model

Policy decides whether. The sandbox limits what.

Approval first

Every tool call is evaluated against a permission lattice: hard-deny → deny rules → ask rules → allow rules → mode table. Shell commands are classified from a real bash AST, never by string matching, and anything opaque (eval, $(…), sh -c "$X") can never match an allow rule.

Sandboxed by default

bubblewrap or Landlock on Linux, sandbox-exec on macOS: the workspace is writable, the system is read-only, $HOME is hidden and the network is off unless you grant it. When no sandbox is available the status bar says so in red.

Secrets stay local

Credential files are refused, API keys are stripped from the sandbox environment, and secret-looking strings in tool output are redacted before the model sees them. There is no telemetry and no update check unless you turn it on.

Auditable

Every call, decision, file change and command is appended to a SHA-256-chained JSONL log per session; wright audit verify proves it was not edited.

install

Homebrew, Go, or a container.

install
$ brew install --cask richardwooding/tap/wright
$ go install github.com/richardwooding/wright/cmd/wright@latest
$ podman run --rm -it -v "$PWD:/workspace:Z" -e ANTHROPIC_API_KEY ghcr.io/richardwooding/wright
